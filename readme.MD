# 🇮🇳 Indian E-Commerce Sales Analytics

## 📊 Project Overview

This project analyzes an Indian e-commerce sales dataset to identify sales trends, customer behavior, product performance, regional performance, payment preferences, and return patterns.

The project follows an end-to-end data analytics workflow:

**Excel → Python → MySQL → Power BI**

The final outcome is an interactive 3-page Power BI dashboard designed to provide business-focused insights for sales and performance analysis.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze overall sales and profitability.
- Identify monthly sales trends.
- Find the highest-performing products and categories.
- Analyze customer behavior and customer types.
- Compare sales performance across Indian states.
- Understand payment-method preferences.
- Analyze product returns and return reasons.
- Study the relationship between discounts and profitability.
- Analyze delivery performance and customer ratings.
- Provide actionable business recommendations.

---

## 🗂️ Dataset

The dataset represents realistic Indian e-commerce transactions.

### Key columns

- Order ID
- Order Date
- Customer ID
- Customer Type
- State
- City
- Product
- Category
- Quantity
- Unit Price
- Discount
- Sales
- Cost
- Profit
- Payment Method
- Delivery Days
- Customer Rating
- Returned
- Return Reason

### Dataset Size

- **12,000 Orders**
- **2,484 Customers**
- **21,948 Units Sold**
